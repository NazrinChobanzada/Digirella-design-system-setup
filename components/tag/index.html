Components

Badge & Tag New

Small markers attached to something else. A badge reports a state the system decided; a tag is a choice the reader can make. The difference is whether it can be pressed — and getting that wrong is the most common mistake with either.

Badge or tag

Four names circulate for these — badge, tag, chip, lozenge — and they are not four components. This system ships two, and the decision between them is one question.

BadgeTag
Is it pressableNo. Never.Yes — it toggles, or it can be removed.
Who decided itThe system. A state it is reporting: Draft, Live, Low stock.The reader. A filter they applied, or a value they picked.
ShapeRectangular at --radius-xsFully pill-shaped at --radius-pill
Element<span><button>, so it is focusable and announced as pressed

The shape difference is doing work here, and it is the same rule the shape foundation applies to buttons: a rectangle reads as something the system stated, a pill reads as something you can toggle. If a marker is pressable it must be a pill, and if it is not pressable it must not be.

Chip and lozenge are other systems' words. A chip is a tag; a lozenge is a badge. Neither is a third component.

Badge

A status marker. Not interactive — it reports, it does not offer.

A selectable filter chip. The ones on the left toggle; the ones on the right can be removed.

Spacing

Badge

The tightest padding in the system, because a badge is a marker rather than an object.

ContextValueToken
Padding2 × 8--badge-padding-y/x
Counter padding0 × 6--badge-counter-padding-x
Dot or icon to text4--badge-icon-gap
Badge to an adjacent title8--badge-adjacent-gap

In a table cell a badge inherits the cell padding — do not add margins around it.

A notification dot overlays its anchor at −4px from the corner, outside the box rather than inset.

Values are read from tokens/spacing-components.css. The rules behind them, and the two places this system diverges from the consensus, are on the spacing page.

Tag

Asymmetric on purpose: 12 on the label side, 8 on the icon side. An icon carries its own whitespace, so equal padding makes it look pushed away from the label.

ContextValueToken
Padding4 × 12--tag-padding-y/x
Icon side8--tag-padding-icon-side
Inner gap8--tag-gap
Tag to tag8--tag-gap
Row gap when wrapped8--tag-row-gap

A wrapped row of tags uses the same 8px vertically as horizontally, otherwise the second row reads as a separate group.

The dismiss icon stays 16px visually but needs a 24px hit area — 48 on touch.

Values are read from tokens/spacing-components.css. The rules behind them, and the two places this system diverges from the consensus, are on the spacing page.

Elevation

None. A tag establishes itself with a border and a fill; a shadow would claim it floats.

SurfaceLevelToken
Rest, hover, selectednone—

Selected tags fill with the brand colour rather than lifting.
