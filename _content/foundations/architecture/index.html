Architecture

Each layer references the one above it. A palette step never appears in a component; a semantic token never hard-codes a hex.

01 · PRIMITIVE
Palette
Raw values. --green-60: #006A09. Never used directly in product code.
02 · SEMANTIC
Intent
Describes purpose. --color-primary, --text-secondary, --surface-card.
03 · COMPONENT
Usage
Button, Input, Card read semantic tokens only. No literal colours.
